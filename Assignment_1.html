Introduction to Web Technologies

HTML CSS JavaScript

HTML - HyperText Markup Language

HTML is the standard markup language used to create web pages. It describes the structure of a Web page using elements like headings, paragraphs, links, and images.

CSS - Cascading Style Sheets

CSS is used to control the style and layout of web pages. It allows you to apply colors, fonts, spacing, and positioning to HTML elements.

JavaScript - Programming the Web

JavaScript is a scripting language that allows you to create dynamically updating content, control multimedia, animate images, and pretty much everything else.
